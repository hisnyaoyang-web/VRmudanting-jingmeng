# 梦入牡丹亭 · 寻回杜丽娘

> 一款以皮影戏长卷为载体的互动叙事体验。玩家以「看客」的身份走入汤显祖《牡丹亭》的世界，操控自己的影子沿着画卷从闺房走向花园，在月门戏台前完成一曲游园惊梦，最终在铜镜里拼合出独属于自己的杜丽娘。

## 特色

- **移动即叙事** —— 全程无任何按键推进剧情，走到哪里故事就发生到哪里
- **皮影美学统一** —— 平面叠层、暖光透射、剪纸镂空，所有视觉元素遵循同一套皮影视觉语言
- **嵌入式中型音游** —— React + R3F 实现的下落音符玩法（WASD + JKL），分三关 45s 演出
- **完整人声对白** —— 闺房敲门、花园问答、镜前对答，全部使用未剪辑的真实音频，字幕按字数比例同步
- **碎片即主题** —— 双手 / 双脚 / 躯干三块碎片对应"织梦 / 择路 / 看客"三层身份隐喻
- **个性化终幕** —— 通关后在镜子前拼合出 4 种杜丽娘形象之一（觉醒 / 探索 / 坚定 / 自由），每次随机
- **可跳过 / 可退出** —— 对白期间右下角常驻「跳过」按钮；音游期间右上角常驻「退出」按钮，可重复进入

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 启动开发服务器
npx tsc --noEmit # 类型检查
npm run build    # 生产构建
npm run preview  # 预览构建产物
```

开发服务器默认运行在 `http://localhost:5173/`，打开根路径即为完整体验。

## 游戏流程

```text
开场说明 → 第一幕 闺房（敲门·双手碎片）
        → 第二幕 月门戏台（音游·3 关）
        → 第三幕 花园（问答·双脚碎片）
        → 铜镜前（拼合·躯干碎片 + 杜丽娘形象）
        → 终幕（题词·亮相·结算）
```

### 第一幕 · 闺房

玩家走向深闺的门，自动触发三次敲门声与三段女训念白（"女子无才便是德 / 不孝有三无后为大 / 三从四德"），门在第 4 次敲击时打开。走出闺房时弹出"杜丽娘 · 双手"碎片。

### 第二幕 · 月门戏台（音游）

走到戏台前触发花园对话（3 句：你是谁 / 我是杜丽娘 / 那我是谁），对话结束后出现「点击进入游戏」按钮。点击后挂载嵌入式音游：

- **三关连演** —— 每关 45s，对应王璐《牡丹亭·游园·皂罗袍》的不同片段
- **落键判定** —— WASD 控制杜丽娘走位，JKL 触发身段动作（见礼 / 疾行 / 飞袖）
- **三档难度** —— 入门 / 正戏 / 名角，影响判定窗口
- **失分控制** —— 第 1 关准确率 < 50% 强制重玩；通过后可选「下一折」或「回到主线」
- **随时退出** —— 右上角「退出」按钮，回到花园对话结束位置，按钮重新出现可重复进入

### 第三幕 · 花园

走出戏台后进入花园，走到对话点自动播放花园问答（3 句完整对白音频），获得"杜丽娘 · 双脚"碎片。

### 铜镜前 · 拼合

走到铜镜前自动播放镜前对白（4 句：我是谁 / 你是杜丽娘 / 我是个看客 / 镜里镜外原分不清），随后三碎片在镜中拼合，弹出独属于本次通关的杜丽娘形象（4 种随机）。

### 终幕

三句牡丹亭经典题词以竖排列高亮轮播："情不知所起，一往而深 / 生者可以死，死可以生 / 生而不可与死……"，皮影人偶以 `hi` 亮相定格。

## 操作方式

| 输入 | 效果 |
| --- | --- |
| ← / → 或 A / D（按住） | 左右移动 |
| 触屏 / 鼠标左半屏按住 | 向左移动 |
| 触屏 / 鼠标右半屏按住 | 向右移动 |
| WASD（音游） | 控制杜丽娘走位 |
| JKL（音游） | 触发身段：见礼 / 疾行 / 飞袖 |

对白期间右下角有「跳过对白」按钮；音游期间右上角有「退出」按钮。其他所有节点全部自动展开。
