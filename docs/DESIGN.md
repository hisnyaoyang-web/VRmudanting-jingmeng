# 梦入牡丹亭 · 寻回杜丽娘 — 设计文档

> 面向设计 / 制作：玩法流程、场景布局、视觉系统、叙事结构、交互规范、资产清单

## 1. 一句话概述

玩家以「看客」的身份走入汤显祖《牡丹亭》的世界，操控自己的影子沿一条连续画卷从闺房走向花园，途中穿过一幕月门戏台（嵌入式音游）。所有剧情靠"走到区域 + 计时器"自动展开，无需按键推进；最终在铜镜前拼合自身碎片，完成"寻回自我"的闭环。

## 2. 核心设计原则

1. **移动即叙事**。没有对话框、没有选项按钮，走到指定区域剧情自动触发。玩家唯一的主动行为是移动。
2. **皮影美学统一**。所有视觉元素 —— 场景、角色、戏台、铜镜 —— 都遵循皮影戏的视觉语言：平面叠层、暖光透射、剪纸镂空。
3. **碎片即主题**。双手、双脚、躯干三块碎片对应"织梦""择路""看客"三层身份隐喻，贯穿全程叙事。
4. **看客即杜丽娘**。玩家开场是旁观者，随着碎片归一，最终成为镜中的杜丽娘本人 —— 4 种形象随机显现，每一次通关都是独一份的"她"。
5. **真实人声贯穿**。对白、敲门、题词都使用未剪辑的录制音频，字幕按字数比例同步出现 —— 不为节奏牺牲声音的完整。

## 3. 全流程

```text
[开场说明] → 第一幕 闺房 → 第二幕 月门戏台 → 第三幕 花园 → [铜镜拼合 · 终幕]
```

完整状态机（12 个状态）：

```text
intro ──[点击开始]──→ approach ──[走到门口]──→ rewardHands
    ──[3.6s]──→ freeRoam ──[走到戏台前]──→ gardenTalk ──[3 句对白结束]──→ talkEnd
    ──[点击「进入游戏」]──→ rhythm ──[3 关音游通关]──→ rewardFeet
    ──[走到镜前]──→ toMirror ──[触发拼合]──→ assemble ──[镜前 4 句对白结束]──→ rewardTorso
    ──[3.6s]──→ finale
```

### 3.1 开场（intro）

显示功能与操作说明页。唯一按钮：「开始体验」。点击后幕布亮起，进入第一幕，主线 BGM 启动（瑞鸣《牡丹亭》342s 循环播放，贯穿全程直到终幕不切换）。

### 3.2 第一幕 · 幽闭闺房（approach → rewardHands）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 走向门 | 向右移动 | 字幕「走向那扇门……」 |
| 到达门口 | 自动 | 系统敲门四次，间隔 `KNOCK_INTERVAL=2.6s` |
| 三段女训 | 敲门 1-3 同步 | 「女子无才便是德」→「不孝有三无后为大」→「三从四德，这是女子的本分」对应三段真实人声 |
| 第 4 次敲门 | 自动 | 门光亮起，门开 |
| 离开闺房 | 自动 | 字幕「不到园林，怎知春色如许」，**完整播放** ~12.4s 真实音频 |
| 获得碎片 | 自动 | 弹出「杜丽娘 · 双手 —— 点亮编织自我人生的能力」，停留 `REWARD_HOLD=4.0s` |

### 3.3 第二幕 · 月门戏台（freeRoam → gardenTalk → talkEnd → rhythm）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 自由游荡 | 向右移动 | 第二幕标题「花园」横幅闪过 |
| 走到对话点 | 自动 | 等入园 quote 念完后开始花园对话 |
| 花园对话 | 自动播放完整音频 | 3 句完整对白：「你是谁？」→「我是杜丽娘。」→「你是杜丽娘，那我是谁？」 |
| 对白结束 | 自动 | 显示「点击进入游戏」按钮（仅在 `talkEnd` 状态显示） |
| 点击按钮 | 玩家点击 | 主线 BGM 暂停，挂载 React 音游 |
| 音游内部 | 自动 | loading → performance（直接跳过原版 intro 掌柜对话），玩家落键 |
| 通关 | 自动 | 弹出关卡选择卡片（重玩 / 下一折 / 回到主线） |
| 退出音游 | 玩家可随时点「退出」 | 卸载音游，回到 talkEnd 状态，按钮重新出现可重复进入 |

**音游细节**：

- **三关连演** —— `level1.mp3 / level2.mp3 / level3.mp3`，每关 45s
- **落键判定** —— 7 轨道 `W/A/S/D/J/K/L`，对应 4 个走位 + 3 个身段
- **三档难度** —— 入门（apprentice）/ 正戏（stage）/ 名角（master），影响判定窗口与音符密度
- **失分控制** —— 第 1 关准确率 < 50% 仅显示「再演这一折」；第 1/2 关通过显示「进入下一折」+「回到主线」；第 3 关通过只显示「回到主线」
- **退出按钮** —— performance 阶段右上角常驻，点击调用 `onExit` 回调

### 3.4 第三幕 · 花园（rewardFeet → toMirror）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 获得碎片 | 音游通关后自动 | 「杜丽娘 · 双脚 —— 拥有选择方向的自由」，停留 4.0s |
| 走向铜镜 | 向右移动 | 铜镜始终在场（不突然出现） |
| 字幕提示 | 自动 | 「镜中似有人影，走近看看。」 |

### 3.5 铜镜前 · 拼合（toMirror → assemble → rewardTorso）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 到达镜面 | 自动 | 进入 `assemble` 状态 |
| 镜前对白 | 自动播放完整音频 | 4 句完整对白：「我是谁？」→「你是杜丽娘。」→「不，我不是杜丽娘。我是个看客罢了。」→「你道你是看客 —— 可这镜里镜外，原分不清谁在看、谁被看。」 |
| 拼合 | 对白结束后 0.4s | 三碎片在镜中归一，显现完整杜丽娘 |
| 获得碎片 | 自动 | 「杜丽娘 · 躯干 —— 你的影子，终成了她自己」+ 本次通关的杜丽娘形象立绘 |

**4 种杜丽娘形象**（每次通关随机抽取一个）：

| 类型 | 关键词 | 题词 |
| --- | --- | --- |
| 觉醒型 The Awakened | 勇敢 · 主动 · 突破束缚 | 「她第一次推开了门，也第一次看见了自己。」 |
| 探索型 The Explorer | 敏感 · 观察 · 寻找 | 「她在花园中寻找春色，也寻找自己的可能。」 |
| 坚定型 The Steadfast | 坚强 · 自我确认 · 主体意识 | 「她不再等待别人定义自己。」 |
| 自由型 The Free | 绽放 · 舒展 · 生命力 | 「想开花，就开花；想绽放，就绽放。」 |

> 对外保留 `computeType()` 接口（"根据行为数据生成专属杜丽娘"），实际内部为 4 种预生成形象的随机抽取，保证每次通关都有变化。

### 3.6 终幕（finale）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 进入终幕 | 拼合后 3.6s | 隐藏奖励卡片，显示终幕页 |
| 皮影亮相 | 自动 | 切换到 `hi` 动作，puppet 发光 |
| 三句题词 | 自动轮播高亮 | 「情不知所起，一往而深。」→「生者可以死，死可以生。」→「生而不可与死……」竖排列常驻显示 |
| 杜丽娘形象 | 自动 | 显示本次通关的类型卡片（4 种之一） |
| BGM | 自动 | 主线 BGM 无缝继续（不切换） |

## 4. 场景布局

### 4.1 长卷分段

```text
0% ──────────── 33.3% ──────────── 66.7% ──────────── 100%
│    闺房（场景1）  │   戏台（中段）   │   花园（场景2）   │
│    s1-back/mid/front │  theatre-half │  s2-back/mid/front │
```

每段场景由三层图片叠加（后景 / 中后景 / 前景），角色轨道夹在中后景与前景之间。

### 4.2 四层叠轴

```text
z=1  后景（最远）   ← 视差最弱
z=2  中后景        ← 视差中等
z=4  铜镜          ← 花园内，角色之后
z=5  角色轨道（人偶）← 皮影人偶在此移动
z=6  前景          ← 视差最强，可遮挡角色（必须保持透明区域）
z=7  接缝阴影
z=8  剪纸屏柱      ← 两幕之间，角色可穿行
```

**关键规则**：角色永远在前景区之前可见。前景图必须在角色活动区域保持透明，否则会遮挡角色。

### 4.3 剪纸屏柱

两幕之间的装饰柱（`.scene-screen`），位于长卷 33.3% 与 66.7% 处。功能是视觉上遮挡场景接缝，角色可穿行其下/其后。柱身用 SVG 描绘（顶冠 / 屏面半透背板 / 棂格 / 中央月洞 / 月洞内折枝牡丹 / 底座），呈现剪纸皮影的镂空质感。

### 4.4 铜镜

位于花园场景最右端 1/3 处。从游戏开始就始终可见，不突然出现。z-index 4，在角色之后 —— 角色走到镜前时不会被遮挡。

### 4.5 月门戏台（音游覆盖层）

走到戏台中心触发后，全屏覆盖 `#rhythm-stage`（position:fixed, z-index:40），内含 React 音游。覆盖层显示期间长卷移动暂停，主线 BGM 暂停，音游 BGM 接管。

## 5. 视觉系统

### 5.1 配色

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--gold` | `#d9a03f` | 金边、描线 |
| `--gold-bright` | `#f0c060` | 高光、奖励 |
| `--ember` | `#d98a3c` | 暖橙、按钮 |
| `--lacquer` | `#8c1f1a` | 漆红 |
| `--lacquer-deep` | `#5c120f` | 深漆红 |
| `--ink` | `#160a10` | 墨色背景 |
| `--paper` | `#f2d8a8` | 纸色（字幕、文字） |

整体基调为暖色系（金 / 橙 / 漆红）叠在墨色暗背景上，营造皮影灯箱的透光质感。

### 5.2 字体

`--serif: "Kaiti SC", "KaiTi", "STKaiti", "TW-Kai", "Noto Serif SC", serif`

楷体为主，呼应古典叙事。

### 5.3 皮影人偶

- **材质**：暗背光 + emissive 暖光，模拟皮影灯箱的透射光感
- **着色器抠像**：剔除编辑器辅助色（绿 / 黄 / 灰），保留皮影本体
- **朝向**：阻尼插值 `scale.x`，平滑转身而非硬翻转
- **投影**：drop-shadow 模拟皮影投在幕布上的影子

### 5.4 动画规范

| 状态 | 实现 | 用途 |
| --- | --- | --- |
| `idle` | 停在 hi 第一帧，静止 | 默认站立 |
| `walk` | 循环 | 左右移动时 |
| `hi` | 单次播放 | 角色亮相 / 确认身份 / 终幕定格 |
| `run` | 循环 | 音游"疾行"键 |
| `flying` | 单次 + Y 位移 | 音游"飞袖"键 |

## 6. 碎片系统

三块碎片对应三层身份隐喻：

| 碎片 | 获得节点 | 含义 |
| --- | --- | --- |
| 双手 | 第一幕闺房门开后 | 点亮编织自我人生的能力 |
| 双脚 | 第二幕音游通关后 | 拥有选择方向的自由 |
| 躯干 | 铜镜拼合后 | 你的影子，终成了她自己 |

铜镜拼合阶段：双手、双脚徽章依次点亮（金色发光），躯干由玩家影子凝聚而成 —— 象征"看客"成为"杜丽娘"的一部分。

## 7. 交互规范

### 7.1 输入

| 输入方式 | 效果 |
| --- | --- |
| 键盘 ← / → 或 A / D（按住） | 左右移动 |
| 触屏 / 鼠标左半屏按住 | 向左移动 |
| 触屏 / 鼠标右半屏按住 | 向右移动 |
| 鼠标移动 | 轻微视差（装饰性） |
| WASD + JKL（音游内） | 落键判定 |

### 7.2 无按键原则

主线剧情全程无任何交互键推进。所有剧情节点（敲门、对白、奖励、拼合、结算）靠"走到区域 + 计时器 / 音频 ended 事件"自动触发。唯一的主动按钮：

- 开场「开始体验」
- 花园对话结束后的「点击进入游戏」（`talkEnd` 状态显示）
- 音游右上角「退出」（可选，可重复进入）
- 对白右下角「跳过」（可选，跳到下一段）
- 关卡选择卡片（重玩 / 下一折 / 回到主线）
- 终幕的「重新体验 / 结束体验」

### 7.3 移动不受限

角色在整条长卷上自由左右移动（`WORLD_LEFT` 到 `WORLD_RIGHT`），不被状态锁定。即使剧情正在播放，玩家仍可自由走动；音游覆盖期间暂停长卷移动。

### 7.4 跳过按钮（对白期间）

`gardenTalk` 与 `assemble` 状态对白播放期间，右下角常驻「跳过对白」按钮。点击立即停止音频、清掉字幕计时器、触发 `onDone` —— 用于不想看完整对白的玩家快速推进。`dialogueToken` 守卫防止旧对白的 setTimeout 残留触发新状态。

## 8. 终幕题词

三句出自汤显祖《牡丹亭·作者题词》，以竖排列常驻显示，活动句按阅读节奏自动轮播高亮（基础 2.6s + 每字 0.18s）：

1. 情不知所起，一往而深。
2. 生者可以死，死可以生。
3. 生而不可与死，死而不可复生者，皆非情之至也。

轮播结束后保留题词显示，仅取消高亮 —— 不强行消失。
