# 梦入牡丹亭 · 寻回杜丽娘 — 设计文档

> 面向设计/制作：玩法流程、场景布局、视觉系统、叙事结构、交互规范

## 1. 一句话概述

一款以皮影戏长卷为载体的互动叙事体验。玩家操控杜丽娘的影子，沿着一条连续画卷从闺房走向花园，途中经过一幕皮影戏台（音游）。全部剧情自动展开，无需按键推进——玩家只需左右移动，走到哪里，故事就发生到哪里。最终在铜镜前拼合自身碎片，完成"寻回自我"的闭环。

## 2. 核心设计原则

1. **移动即叙事**。没有对话框、没有选项按钮，走到指定区域剧情自动触发。玩家的唯一主动行为是移动。
2. **皮影美学统一**。所有视觉元素——场景、角色、戏台、铜镜——都遵循皮影戏的视觉语言：平面叠层、暖光透射、剪纸镂空。
3. **碎片即主题**。双手、双脚、躯干三块碎片对应"织梦""择路""看客"三层身份隐喻，贯穿全程叙事。

## 3. 全流程

```text
[开场说明] → 第一幕 闺房 → 第二幕 戏台音游 → 第三幕 花园 → [结算]
```

### 3.1 开场

显示功能与操作说明页。唯一按钮："开始体验"。点击后幕布亮起，进入第一幕。

### 3.2 第一幕 · 幽闭闺房

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 走向门 | 向右移动 | 字幕"走向那扇门……" |
| 到达门口 | 自动 | 字幕自动敲门四次（每 1.8s 一次）："女子无才便是德"→"不孝有三"→"三从四德"→三声齐至门开 |
| 门开后 | 自动 | 字幕"不到园林，怎知春色如许"，停留 4.5s |
| 获得碎片 | 自动 | 弹出"杜丽娘 · 双手——点亮编织自我人生的能力"，停留 3.6s |

碎片获得后自由移动，穿过剪纸屏柱进入第二幕。

### 3.3 第二幕 · 月门戏台（音游）

| 节点 | 触发 | 内容 |
| --- | --- | --- |
| 走到戏台中心 | 向右移动 | 戏台覆盖层立即出现，React 音游自动挂载 |
 | | | intro 对话自动播放（无需点击），自动进入表演 |
 | | | 下落音符 + 键盘判定（WASDJKL），原版玩法保留 |
 | | | 音乐结束 → outro 自动播放 → 自动回调 |
 | | | 字幕"一曲既罢，再向前便是花园" |

走出戏台后自由移动，穿过第二道接缝进入第三幕。

### 3.4 第三幕 · 花园

| 节点 | 触发 | 内容 |
| --- | --- | --- |
 | 走到对话点 | 向右移动 | 自动对话六句（每 3.2s）：杜丽娘亮相（hi 动作）→"请随我来" |
 | 获得碎片 | 自动 | "杜丽娘 · 双脚——拥有选择方向的自由"，停留 3.6s |
 | 走向铜镜 | 向右移动 | 铜镜始终在场（不突然出现） |
 | 到达镜面 | 自动 | 镜面模糊 → 自动拼合（1.2s 双手 / 2.6s 双脚 / 4.0s 清晰 / 5.4s 躯干 / 6.8s 完成） |
 | 拼合对话 | 自动 | "我是谁？"→"你是杜丽娘"→"我是个看客"→"每个人的灵魂里都有一个杜丽娘" |
 | 获得碎片 | 自动 | "杜丽娘 · 躯干——你的影子，终成了她自己" |
 | 水波过场 | 自动 | 水波覆盖幕布 2.2s |
 | 结算 | 自动 | 完整杜丽娘亮相（hi）+ 评级 + 关键词 + 重新/结束按钮 |

## 4. 场景布局

### 4.1 长卷分段

```text
0% ──────────── 33.3% ──────────── 66.7% ──────────── 100%
│    闺房（场景1）  │   戏台（中段）   │   花园（场景2）   │
│    s1-back/mid/front │  theatre-half │  s2-back/mid/front │
```

每个场景段由三层图片叠加（后景、中后景、前景），角色轨道夹在中后景与前景之间。

### 4.2 四层叠轴

```text
z=1  后景（最远）   ← 视差最弱
z=2  中后景        ← 视差中等
z=4  铜镜          ← 花园内，角色之后
z=5  角色轨道（人偶）← 皮影人偶在此移动
z=6  前景          ← 视差最强，可遮挡角色（必须保持透明区域）
z=7  接缝阴影
z=8  剪纸屏柱      ← 两幕之间，角色可穿行
```

**关键规则**：角色永远在前景区之前可见。前景图必须在角色活动区域保持透明，否则会遮挡角色。

### 4.3 剪纸屏柱

两幕之间的装饰柱（`.scene-screen`），位于长卷 33.3% 处。功能是视觉上遮挡场景接缝，角色可穿行其下/其后。带轻微摆动动画。

### 4.4 铜镜

位于花园场景最右端 1/3 处（`left: 89%`）。从游戏开始就始终可见，不突然出现。底部与皮影人偶同一水平线（`bottom: 9%`），上移自身高度的 27%（`translateY(-27%)`）。z-index 4，在角色之后——角色走到镜前时不会被遮挡。

## 5. 视觉系统

### 5.1 配色

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `--gold` | `#d9a03f` | 金边、描线 |
| `--gold-bright` | `#f0c060` | 高光、奖励 |
| `--ember` | `#d98a3c` | 暖橙、按钮 |
| `--lacquer` | `#8c1f1a` | 漆红 |
| `--lacquer-deep` | `#5c120f` | 深漆红 |
| `--ink` | `#160a10` | 墨色背景 |
| `--paper` | `#f2d8a8` | 纸色（字幕、文字） |

整体基调为暖色系（金/橙/漆红）叠在墨色暗背景上，营造皮影灯箱的透光质感。

### 5.2 字体

`--serif: "Kaiti SC", "KaiTi", "STKaiti", "TW-Kai", "Noto Serif SC", serif`

楷体为主，呼应古典叙事。

### 5.3 皮影人偶

- 材质：暗背光 + emissive 暖光，模拟皮影灯箱的透射光感
- 着色器抠像：剔除编辑器辅助色（绿/黄/灰），保留皮影本体
- 朝向：阻尼插值 scale.x，平滑转身而非硬翻转
- 投影：drop-shadow 模拟皮影投在幕布上的影子

### 5.4 动画规范

| 状态 | 实现 | 用途 |
| --- | --- | --- |
| `idle` | 停在 hi 第一帧，静止 | 默认站立 |
| `walk` | 循环 | 左右移动时 |
| `hi` | 单次播放 | 角色亮相/确认身份 |
| `run` | 循环 | 快速离场（预留） |
| `flying` | 单次 + Y 位移 | 飞袖（预留） |

## 6. 碎片系统

三块碎片对应三层身份隐喻：

| 碎片 | 获得节点 | 含义 |
| --- | --- | --- |
| 双手 | 第一幕闺房 | 点亮编织自我人生的能力 |
| 双脚 | 第三幕花园对话后 | 拥有选择方向的自由 |
| 躯干 | 铜镜拼合 | 你的影子，终成了她自己 |

铜镜拼合阶段：双手、双脚徽章依次点亮（金色发光），躯干由玩家影子凝聚而成——象征"看客"成为"杜丽娘"的一部分。

## 7. 交互规范

### 7.1 输入

| 输入方式 | 效果 |
| --- | --- |
| 键盘 ← / → 或 A / D（按住） | 左右移动 |
| 触屏/鼠标左半屏按住 | 向左移动 |
| 触屏/鼠标右半屏按住 | 向右移动 |
| 鼠标移动 | 轻微视差（装饰性） |

### 7.2 无按键原则

全程无任何交互键推进剧情。所有剧情节点（敲门、对话、奖励、拼合、结算）靠"走到区域 + 计时器"自动触发。唯一的按钮是开场"开始体验"和结算"重新体验 / 结束体验"。

音游阶段保留原版键盘玩法（WASDJKL 判定），但进入和退出音游本身不需要任何按键——走到戏台中心自动启动，音乐结束自动退出。

### 7.3 移动不受限

角色在整条长卷上自由左右移动（`WORLD_LEFT` 到 `WORLD_RIGHT`），不被状态锁定。即使剧情正在播放，玩家仍可自由走动。

## 8. 结算

完整杜丽娘拼合后播放 `hi` 亮相。结算页显示：
- "你的杜丽娘"
- 结果类型（镜中人）
- 关键词（寻回 · 觉醒 · 自由）
- 结算文字
- "重新体验" / "结束体验" 按钮
